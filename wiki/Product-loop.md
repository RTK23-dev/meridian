# Product loop

Each step is a screen. A missing key, connection, or piece of evidence is named on that screen. A button that cannot act says why.

| Step | What you do | What Meridian stores |
| --- | --- | --- |
| Brand brain | Positioning, audience, voice, rules, assets | Only the fields you save. Empty fields stay empty |
| Products | The products the brand sells | The product a brief names |
| Market | Public pages and connected sources | Each item keeps where it came from |
| Opportunities | Review the angles | The evidence each angle cites |
| Studio | Approve a brief, then generate | The variant, its evidence, its decision, and its review |
| Content Factory | Run the same loop as staged jobs, or start one video from a chat | The run settings, the stop point, and the request id |
| Library | Look at creatives that exist | Media and lineage. An export package for manual posting |
| Publishing | Send an organic post, or create a paid ad | A receipt only when the platform returns an id. Paid ads are created paused |
| Learning | Read what was measured | Observed numbers only. A stored grade is not rewritten later |

## Roles

Owners and admins change settings, keys, and brands. Members create and review. Viewers read. Every change checks the role on the server.

## Video

Gemini Omni, Hypit, Higgsfield, and a manual cloud folder are the video paths. Hypit runs as its own process. If it is not running, that job is not connected. No price is invented for a render: a bill is stored only when the provider reports one.
