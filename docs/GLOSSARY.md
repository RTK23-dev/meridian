# Meridian glossary

- **JEV**: The decision engine that evaluates evidence, confidence, and policy. It recommends or routes a decision while configured approval steps remain in place.
- **Hypit**: The video production engine. It renders from an approved brief and stores the returned video artifact.
- **JEV Research**: The upstream advertising intelligence layer that stores source-backed analysis and observed patterns; it informs JEV decisions but does not approve work itself.
- **Paused Meta publication**: A provider-confirmed Meta video/campaign/ad-set/creative/ad chain created with delivery paused. It is not an active campaign.
- **Confidence**: How strongly the stored evidence supports a decision. It is not a guarantee of future advertising performance.
- **Opportunity**: A ranked creative direction based on the evidence Meridian has stored for a brand.
- **NOT_CONNECTED**: Meridian has no verified working connection for that provider. The feature does not substitute a test provider or report a live result.
