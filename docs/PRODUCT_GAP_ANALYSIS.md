# Product gap analysis

Audited against the advertising-intelligence loop, not against the presence of a screen. Status is what the running code does after this reconstruction.

What is still not true: ad library, publishing, neural embeddings, video, PDF extraction, and a performance feed are not connected, and they return that state instead of invented results. Text and DOCX can be stored as untrusted source material. Logos are stored as bytes on the brand, not in an external object store. Organization patterns apply only after a brand opts in; global patterns never apply. There is no always-on worker. Lexical similarity is not semantic understanding. Calibration does not move thresholds. Cost stays null unless a provider reports it. The acceptance test proves the decision loop on stored evidence. It does not prove a live ad account.
