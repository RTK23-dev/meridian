revision paths, the provider connection state, the gateway and the Claude client. Five read-only reviews ran in parallel, one per area.

## Open, with the decision each needs

1. **A timed-out Claude call is paid again on retry (high).** `runRole` rethrows after a timeout, and the retry takes a new idempotency key
   (`client.ts`, the attempt suffix). A call that OpenRouter billed before the timeout is therefore paid twice, and its hold never gets a
   bill. Decision: keep one key per role call across job attempts, so the ledger refuses a second charge for the same call.
2. **The orchestrator plan's input estimate is fixed at 8000 tokens (medium).** A full catalog can be larger, so the hold can be short of
   the real call. Decision: size the estimate from the real prompt.
3. **Orchestrator step prices use the input tokens the model wrote (high, latent).** `validate.ts` prices analysis and script steps from
   `input_tokens` in the plan, which the model writes. A model can understate the estimate. Decision: derive the bound from the reference
   and the brief, on the server.
4. **A plan's reservation is not released after success (medium, unverified).** Only some flows release their unused hold. Decision:
   check the release path for plan calls and release the unused part.
5. **A stored credential that the status accepts but the jobs refuse (high).** The status reads the first credential row, while the metric
   jobs read a different one, so the status can say Connected while every run fails. Decision: one source of credential state for both.
6. **Token expiry is not stored (medium).** A success from earlier stays HEALTHY after its token expires. Decision: store the expiry and
   show DEGRADED when it has passed.
7. **Environment-based provider status (low, known).** `system.ts` reads deployment variables for provider status. The beta.14 notes say
   this waits for the owner. Recorded as an owner decision on 2026-10-22 (PHASE_LOG); the code is unchanged.
8. **Relevant to a deployment without a credential (latent).** The gateway treats a credentialed provider with no credential id as
   connected and sends no key. Only `media_functions` is configured that way today.
9. **A revision can start while a remake of the same request runs (medium, unverified).** Needs concurrent calls to reproduce. Fixed and tested
   on 2026-10-22; see the status table.
10. **A plan's model field is not checked against the plan's own orchestrator id in one path (low, no caller yet).** `planWithModel`.
11. **Smaller items (low):** the `not started` text for a failure after render; the scripted-request copy; a concurrent start shows the raw
    database error; an audit failure after a start is reported as an error; a Drive object from a session started mid-upload is left
    unreferenced; the TikTok publish path still reads the environment advertiser id.
