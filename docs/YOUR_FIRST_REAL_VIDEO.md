# Your first real video

This is the short version, in plain words. It is for the person who holds the keys. The longer, more technical order is in
[FIRST_TEST_RUN.md](FIRST_TEST_RUN.md). Nothing here has been run against a live provider yet, so read "What to expect" before you spend.

## What you are trying to find out

One question: **does Meridian make one video you would actually post?** If it does, scale up. If it does not, stop and say what was wrong.
Do not set up everything first. Each step below says whether you need it.

## Before you start (about 10 minutes, no money spent)

1. Run `npm run dev` and open http://127.0.0.1:8080. Create an account, a workspace and one brand (a name and what it sells).
2. Open the Setup guide. It shows only two things to do. Do them:
   - **A brand.** You just made one.
   - **One key for the service that judges your ideas.** If you have a TypeSafe key, choose TypeSafe JEV and paste it. Otherwise OpenAI or
     OpenRouter. You need only one.
3. Open **Billing** and set the **monthly budget** to a small number, for example $10. Meridian will not spend anything until you do, and it
   stops at that number. Set the brand budget to the same.
4. On the brand, open **Content**, then **Batch**, and press **Try a demo batch**. It uses made-up data, costs nothing, and shows you what a
   batch, a review and an export look like. Every part says DEMO.

## What you need before a real video, and what you do not

| Item | Do you need it? |
| --- | --- |
| The decision key from step 2 | Yes |
| A key for the service that makes the video (Gemini, OpenRouter, Higgsfield or similar) | Yes, to make a video. Not to look around |
| Google Drive connected | Only to upload a reference video. Without it you can still write a brief |
| Publishing accounts (Facebook, YouTube, TikTok) | No. Export the file and post it yourself for now |
| Search keys, Shopify, Apify, email | No |

## The real run (spends money, keep it small)

1. Put one example video you like on **Content**. Upload it as a file (a link is not enough). Paste two or three public pages about the niche on
   **Market**; no key is needed for that.
2. Make **one** draft from it and write what the videos should be about in plain words.
3. Choose **2** videos, not 20, and a total budget of a few dollars. Look at the sample of the first video before you start the batch.
4. Press **Start the batch**. Each video shows its real state. A video is only "done" when the engine recorded a file.
5. Open the result. Watch it. Ask: would I post this? Is it original, or too close to the example?

## What to expect

- **Costs are real once a video key is saved.** The budget you set is a hard limit, but each video can cost several dollars.
- **Nothing is verified live yet.** The first run is the first time any provider is called. Something may fail. When it does, the screen says
  which step failed and why. Copy that text, it is what is needed to fix it.
- **Meridian does not make money by itself.** It makes drafts. Whether a video earns depends on what you post and where. Decide that after you
  have seen one real video.

## After the run

Write down three things: what it cost, how long it took, and whether you would post the video. If the answer to the last one is no, the most
useful thing is to say what was wrong with it (too generic, wrong style, wrong length, looks fake). That tells us what to change next, before any
more features are built.
